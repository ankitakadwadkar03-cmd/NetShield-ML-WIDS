# NetShield-ML-WIDS

NetShield is an ML-based WiFi intrusion detection,
real-time security monitoring and signal analysis system.

## Main Components

- WiFi Network Scanner
- Signal Analysis
- Vendor Lookup
- Live Packet Capture
- Feature Extraction
- Machine Learning Intrusion Detection
- Attack Classification
- PCAP Analysis
- Security Incidents
- Evidence and Recommendations
- Reports

## Technology

Frontend:
React + Vite

Backend:
Python + Flask

Machine Learning:
scikit-learn

Database:
SQLite

Platform:
Kali Linux
